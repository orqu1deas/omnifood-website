# Omnifood — Responsive Food Delivery Website

**Omnifood** es una landing page moderna y completamente adaptativa para una empresa ficticia de suscripción de comida saludable impulsada por IA. Este proyecto fue desarrollado como el proyecto final del popular curso de Udemy **"Build Responsive Real-World Websites with HTML and CSS"** dictado por Jonas Schmedtmann.

El objetivo principal de este proyecto fue aplicar conceptos avanzados de diseño web, maquetación moderna, optimización de rendimiento y diseño _Mobile-First_.

---

## 🚀 Características del Proyecto

El sitio web simula un servicio real e incluye las siguientes secciones y componentes:

- **Navegación Inteligente:** Barra de navegación fija (_sticky navigation_) con efecto de desplazamiento suave (_smooth scrolling_).
- **Sección Hero:** Introducción de alto impacto con llamadas a la acción (CTA) claras y optimizadas.
- **Cómo Funciona:** Un diseño estructurado paso a paso que detalla la experiencia del usuario.
- **Galería de Comidas:** Grilla interactiva que muestra categorías de alimentos, atributos nutricionales (dietas como Keto, Vegana, Paleo) y tarjetas de recetas detalladas.
- **Testimonios e Integración:** Sección de opiniones de clientes reales integrada con una galería fotográfica adaptativa.
- **Planes de Precios:** Tablas de precios comparativas claras junto con los beneficios incluidos en cada suscripción.
- **Formulario de Registro:** Formulario interactivo y estilizado para captación de clientes.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración semántica avanzada para SEO y accesibilidad.
- **CSS3 moderno:** Uso intensivo de **Flexbox** y **CSS Grid** para la arquitectura de componentes y la composición de la página.
- **Diseño Responsivo:** Uso de _Media Queries_ fluidas para garantizar una visualización perfecta en smartphones, tablets y pantallas de escritorio.
- **JavaScript (Vanilla):** Implementación de la funcionalidad del menú móvil (hamburguesa) y el comportamiento de la navegación fija.
- **Optimización Web:** Uso de formatos de imagen modernos (WebP), fuentes optimizadas y buenas prácticas de rendimiento.

## 📦 Instalación y Uso Local

Si deseas clonar el proyecto y ejecutarlo en tu máquina local, sigue estos pasos:

1. **Clona este repositorio:**

   ```bash
   git clone https://github.com
   ```

2. **Navega al directorio del proyecto:**

   ```bash
   cd TU_REPOSITORIO
   ```

3. **Abre el archivo principal:**
   Abre el archivo `index.html` en cualquier navegador web o utiliza la extensión _Live Server_ en VS Code.
